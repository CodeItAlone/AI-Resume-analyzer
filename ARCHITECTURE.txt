1. OVERVIEW
-------------------------------------------------------------------------------
AI Resume Analyzer is a single-session, privacy-first web application designed
for transparent, objective resume-to-job match scoring. It eliminates AI score
bias by executing pure deterministic mathematical calculations while using an LLM
strictly for structured JSON extraction and factual feedback generation.

3. CORE MODULE RESPONSIBILITIES
-------------------------------------------------------------------------------
- app/api/analyze/route.ts
  Main Next.js serverless API endpoint. Coordinates extraction, parsing,
  scoring, and response generation.

- lib/extractor.ts
  Server-side text extraction engine. Runs pdf2json for PDF documents and mammoth
  for Word documents without browser DOM dependencies.

- lib/ai.ts
  OpenRouter API integration for structured JSON parsing of resumes & job
  postings, joint vocabulary vector space creation, and factual feedback generation.

- lib/scorer.ts
  Pure-function deterministic scoring math. Computes Skills Match (with synonym
  normalization), Experience Match, Education Match, Semantic Match, and the
  locked 40/25/15/20 overall score sum.

- lib/types.ts
  Central TypeScript interface definitions for Resume Data, Job Description Data,
  Subscores, Skills Matrix Items, and Analysis Response payloads.

- components/ResumeDocument.tsx
  Main manuscript document view (~70% width). Renders candidate text with inline
  color-coded skill underlines.

- components/MarginNote.tsx
  Pinned editor margin notes (~30% width) displaying missing skill callouts,
  strengths, and revision advice.

- components/ScoreStamp.tsx
  Double-strike rotated verdict stamp with registration offset layer simulating
  physical ink stamping.

- components/ProcessingState.tsx
  Staged processing indicator showing 5 sequential analysis pipeline steps.


4. DETAILED SCORING FORMULA
-------------------------------------------------------------------------------
- Skills Match (40% Weight):
  Matches resume skills against required & preferred skills.
  Exact/synonym match = 100%, Partial match = 50%, Preferred skill bonus up to +15%.

- Experience Match (25% Weight):
  Ratio of candidate years of experience to job required years.

- Education Match (15% Weight):
  Hierarchical degree level ranking (High School < Associate < Bachelor's < Master's < PhD).

- Semantic Similarity (20% Weight):
  Cosine similarity over aligned joint vocabulary term frequencies.

- Overall Score Formula:
  Score = Math.round(Skills * 0.40 + Experience * 0.25 + Education * 0.15 + Semantic * 0.20)
